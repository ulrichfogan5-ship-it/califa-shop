# CALIFA SHOP — version complète 14 étapes

## Lancement
1. Ouvrir ce dossier dans VS Code.
2. Dans le terminal : `npm start`
3. Ouvrir : http://localhost:3000
4. Administration : http://localhost:3000/admin/admin.html

## Les 14 étapes incluses
1. Panier moderne et quantités
2. Favoris
3. Recherche instantanée
4. Promotions / anciennes valeurs
5. Page produit détaillée
6. Historique des commandes par email
7. Création de compte + connexion
8. Interface Orange Money / MTN MoMo en MODE TEST
9. Administration des commandes et statistiques
10. Responsive téléphone / tablette / PC
11. Avis et notes produits
12. Notifications
13. Informations de livraison lors de la commande
14. Mode sombre / clair + base Node.js

## Images
Les photos des produits sont chargées directement depuis Internet (URLs HTTPS). Aucun dossier images local n’est nécessaire.

## Paiement
Orange Money et MTN MoMo sont des simulations locales. Aucun argent réel n’est débité. Pour un vrai paiement, il faudra intégrer les API officielles d’un compte marchand côté serveur et ne jamais exposer les clés dans le navigateur.
